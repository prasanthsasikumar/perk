# Perk v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship Perk v1 — a multi-tenant SaaS where coffee shops sign up, configure a stamp card, and customers get it in Apple Wallet / Google Wallet / web, with barista-scan and customer-scan stamping and a shop dashboard.

**Architecture:** One Next.js 16 App Router app on Vercel. Drizzle ORM over Supabase Postgres (pglite in tests). A pure domain layer (`lib/domain`) runs every card mutation in a transaction and returns events; the route/action layer then fans out wallet updates via `waitUntil`. A `WalletProvider` interface with Apple and Google implementations. Auth.js v5 magic links for owners; a signed PIN cookie for staff; bearer card ids for customers.

**Tech Stack:** Next.js 16.3, React 19.2, TypeScript, Tailwind 4, drizzle-orm 0.45 + `postgres` 3.4, `@electric-sql/pglite` 0.5 (tests), `next-auth@5.0.0-beta.32` + `@auth/drizzle-adapter`, `resend`, `passkit-generator` 3.5, `jose` 6, `google-auth-library` 11, `sharp`, `@resvg/resvg-js`, `qrcode`, `html5-qrcode`, `@vercel/functions`, `@supabase/supabase-js` (Storage only), Vitest 4, Playwright.

**Spec:** `docs/superpowers/specs/2026-08-31-perk-v1-design.md`

## Global Constraints

- Node 22, npm (no pnpm/yarn). Next.js 16: use `proxy.ts` not `middleware.ts`; `params`/`searchParams`/`cookies()`/`headers()` are async.
- Every data-access and domain function takes `shopId: string` as its **first** argument. Dashboard code derives `shopId` from the session, never from URL input.
- All card mutations run inside one `db.transaction` with `FOR UPDATE` on the card row.
- Wallet failures are logged, never thrown to the user action.
- No secrets in the repo. Certs/keys are base64 PEM in env vars. `.gitignore` already excludes `.env*`, `*.pem`, `*.p12`, `certs/`.
- Slug is immutable after onboarding. `slug` regex: `^[a-z0-9](?:[a-z0-9-]{1,38}[a-z0-9])?$`, reserved: `api, dashboard, login, onboarding, logout, admin, static, _next, favicon.ico, robots.txt, sitemap.xml`.
- Defaults: `stamps_required=10`, `customer_scan_cooldown_min=15`, `brand_color='#1f1f1f'`, `program_type='stamps'`.
- Env names exactly as spec §11. `WALLET_DRY_RUN=1` skips real signing/HTTP in wallet providers.
- Commit after every task with a conventional-commit message; trailer `Co-Authored-By: Claude Fable 5 <noreply@anthropic.com>`.
- Tests: `npm test` = `vitest run`. Domain/query tests use pglite via `tests/helpers/db.ts`.

  cached = { ...parsed, WALLET_DRY_RUN_BOOL: parsed.WALLET_DRY_RUN === "1" || parsed.WALLET_DRY_RUN === "true" };
  return cached;
}

/** Decode a base64-encoded PEM env var; returns undefined if unset. */
export function pemFromEnv(v: string | undefined): string | undefined {
  if (!v) return undefined;
  return v.includes("-----BEGIN") ? v : Buffer.from(v, "base64").toString("utf8");
}

```ts
export async function checkRateLimit(db: DbOrTx, key: string, limit: number, windowMs: number, now = new Date()) {
  const windowStartCutoff = new Date(now.getTime() - windowMs);
  const [row] = await db.insert(rateLimits).values({ key, count: 1, windowStart: now })
    .onConflictDoUpdate({ target: rateLimits.key, set: {
      count: sql`CASE WHEN ${rateLimits.windowStart} < ${windowStartCutoff} THEN 1 ELSE ${rateLimits.count} + 1 END`,
      windowStart: sql`CASE WHEN ${rateLimits.windowStart} < ${windowStartCutoff} THEN ${now} ELSE ${rateLimits.windowStart} END`,
    }}).returning();
  return { allowed: row.count <= limit, remaining: Math.max(0, limit - row.count) };
}
```
Staff cookie format: `base64url(json) + "." + base64url(hmac)`. Use `crypto.timingSafeEqual`.

- `stampCard`: lock card (`FOR UPDATE`) where `id = cardId AND shop_id = shopId` else `CardNotFound`. If `who.source === 'barista_scan'` and `lastStampedAt` within 5s → return current card with `duplicate: true`, no events. If `who.source === 'customer_scan'` and `lastStampedAt + shop.customerScanCooldownMin*60s > now` → throw `CooldownActive(retryAt)`. Else `stamps += 1`; insert `stamp` event (delta 1). If `stamps >= shop.stampsRequired` → `stamps = 0`, `rewardsAvailable += 1`, insert `reward_earned` event (delta 0), `rewardEarned: true`. Set `lastStampedAt = now`, `updatedAt = now`.
- `redeemReward`: lock; if `rewardsAvailable < 1` throw `NoRewardAvailable`; decrement; `redeem` event; `updatedAt = now`.
- `adjustStamps`: lock; `next = stamps + delta`; if `next < 0` → 0; if `next >= stampsRequired` → `rewardsAvailable += 1`, `next = 0`, also `reward_earned` event; `adjust` event with actual applied delta and `note`; `updatedAt = now`.
